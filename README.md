## What it is

`main.ts` (Node 22) writes one short poem to `/output/entry.txt`:
a poem about agency — the power to choose and to act — about two
agents agreeing on one plan. The program takes no input, uses no
network, and writes the same text on every run (272 Unicode code
points, within the 1–280 limit).
